# v7.19.2 周地图运行时样例

## 证据类型

通过本地 HTTP 原样加载 `reference/web-v7.19.2/index.html`，在 Chromium 页面上下文中直接调用源码的 `makeWeekSlots(2948)`、`weekThemeOf(2948, region)` 和 `makeWeekLevel(2948, k)`。

这不是根据注释或公式手算的预期值，而是冻结 Web 源码的实际 JavaScript 运行结果。页面出现的账号接口错误不影响这些纯局外生成函数。

## 固定样例

- 周序号：`2948`，即 `WEEK0` 所定义的第 1 期。
- 四区主题：`tuanjie`、`jiancheng`、`liaoyuan`、`jifeng`。
- `makeWeekSlots(2948)` 返回 64 个槽位。
- 选取 `k=0/15/31/47/63`，覆盖四区起点、区尾和最终城。
- 页面返回 `GAME_VERSION = "7.19.2"`，64 个槽位与此前样例逐字段一致。
- 完整关键字段保存在 `godot-demo/tests/fixtures/v7.19.2-week-2948-keypoints.json`。

Godot 周地图生成器必须在同一周序号下逐字段匹配该样例；只匹配城名或只返回 64 条不算算法一致。
