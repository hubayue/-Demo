## 完成定义

每一项只有同时满足以下四条才可标记完成：

1. Godot 中存在真实可操作实现，而非名称、占位图或调试绘制。
2. 关键规则有自动化测试或固定种子运行证据。
3. 480×800 实际窗口截图与 Web 同状态截图完成对照。
4. 输入事件序列一致，包括按下、移动、松开、取消和错误落点反馈。

允许偏差只包括字体栅格化和不同渲染器造成的细微抗锯齿。布局、尺寸、信息、色彩层级、命中区、时序和结果不属于允许偏差。

状态：`⬜ 未开始`、`🟡 已有规则但表现/交互不完整`、`✅ 已对照验收`、`— 单机替代`。
