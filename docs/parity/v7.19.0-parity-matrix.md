# v7.19.0 Web → Godot 单机复现矩阵

## 权威与完成定义

- 权威源码：`reference/web-v7.19.0/index.html`
- 权威更新日志：`reference/web-v7.19.0/changelog.html`
- 目标：在没有账号和服务器的情况下，完整保留老板 Demo 的单机内容、规则、页面流程、操作反馈和主要视听体验。
- “完成”必须同时具备：Godot 实现、自动规则证据、实际窗口可玩证据、与 Web 对照记录。只有源码中出现名称或只有页面骨架不算完成。

状态：`✅ 已验证`、`🟡 部分实现`、`⬜ 未迁移`、`— 单机替代`。

## 当前结论

现有 Godot 工程只证明了主流程骨架、输入链路和星级数学可运行。它没有覆盖完整内容和真实战斗，因此完整复现目标仍处于早期阶段。后续以本矩阵逐项关闭，不以“能从标题点到战斗”替代全量完成审计。
