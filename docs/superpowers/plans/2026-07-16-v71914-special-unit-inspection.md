# v7.19.14 特殊单位规则与点将面板复刻计划

## 目标

让 Godot 中的粮仓、龙蛋、应龙不仅外观接近网页 Demo，而且使用同一套生产、孵化、伤害与账本数据，完成三类特殊单位点将面板的一一对应验收。

## 验收标准

- 粮仓只在相邻八格存在未满 15 星的普通武将时产粮，优先喂最低星目标。
- 粮仓产率、喂星成本、升星回血和累计进度与 Web v7.19.14 公式一致。
- 龙蛋面板展示真实阶数、孵化把握及每项加成来源。
- 应龙面板展示与实际吐息共用的单体重击、范围伤害和龙序增幅。
- 三类面板不出现普通武将大招信息，只显示 Web 对应账本和适用宝地/状态。
- 480×800 网页/Godot 各生成粮仓、龙蛋、应龙成对截图，完整测试集通过。

## 实施顺序

1. 在战斗环境测试中加入粮仓产率、无目标停产、最低星喂养、升星满血测试。
2. 新增特殊单位点将面板测试，先固定三类账本文案和真实数值。
3. 实现粮仓规则；抽取应龙伤害函数并由战斗和面板共用。
4. 在点将面板规格和绘制中加入特殊单位分支。
5. 生成成对截图、运行完整回归、复核差异并更新复刻矩阵。
