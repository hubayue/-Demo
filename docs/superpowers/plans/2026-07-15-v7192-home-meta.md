# Web v7.19.2 首页与局外成长复现计划

目标：补齐当前 Godot 版本与老板 Web Demo 最明显的局外层差距，让首页不只是“点空白开战”，而是能查看和养成武将、查看主公成长、使用寻访与背包，并把这些本地成长真实带进下一局战斗。排行榜、账号、云存档和广告继续使用离线替代，不引入服务器。

## 权威与边界

- 规则权威：`reference/web-v7.19.2/index.html` 的 `heroUpCost`、品质表、里程碑、突破/转生、主公府、寻访、物品与成就定义。
- 静态内容：`godot-demo/data/content-v7.19.2.json` 已包含 `hero_tiers`、`rarities`、`milestones`、`techs`、`achievements`、`items` 和主公被动。
- 本地替代：`user://v7.19.2-local-profile.json` 代替账号、云端和服务器；排行榜只展示本地势力/韬略摘要，不伪造在线玩家。
- 不复刻广告变现、登录、云同步和后台接口。

## 验收标准

- [x] 首页显示金币、势力/韬略摘要，并有图鉴、主公府、寻访、成就、背包入口；点空白仍可直接出征。
- [x] 45 将图鉴可分页查看品质、局外等级、里程碑与绝技；金币升级、10/20 级突破石门槛、30 级后转生上限、全额重置按 Web 口径执行并持久化。
- [x] 主公府两页展示 8 位主公的等级、经验、招牌技档位、已解锁/待解锁被动与专属定位。
- [x] 通关发放本地寻访令牌；寻访棋盘、金币/武将经验/主公经验/突破石奖励和背包库存形成可运行闭环。
- [x] 成就至少对已实现且可客观验证的战斗/成长条件自动解锁、可领取金币；未接入条件明确显示未统计，不伪造完成。
- [x] 新成长值真实进入战斗：英雄攻血/登场星/绝技里程碑和主公被动继续通过现有战斗测试验证。
- [x] 新增专项测试、既有 Godot 测试、13 项 Web 测试、编辑器导入与真实首页截图全部通过。

## 实施顺序

1. 先写英雄升级、突破、转生、重置、经验自动升级与本地存档往返的失败测试。
2. 新建纯规则 `hero_progression.gd`，扩展本地档案的英雄经验、突破石、寻访令牌、成就与统计字段。
3. 实现首页五入口、45 将图鉴分页、武将详情和真实养成操作。
4. 实现主公府两页，只读现有主公成长并解释战斗中已生效的被动。
5. 实现离线寻访、背包与可验证成就；通关/讨伐结算发放对应本地资源。
6. 补全本地势力/韬略摘要、真实渲染截图、全量回归、提交并推送。
