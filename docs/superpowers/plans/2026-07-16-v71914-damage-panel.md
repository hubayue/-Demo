# v7.19.14 实时输出面板复刻计划

## 目标

把当前只列四名武将累计值的简化面板，替换为 Web v7.19.14 的统一伤害账本：记录实际扣血、武将与系统来源、近十秒秒伤、累计占比、零输出够不着提示和结算输出前三。

## 验收

- 所有伤害从唯一伤害闸门记账，护盾计入、溢出伤害不计。
- 同名武将合并，主公/盾反/火燎/乱石/遗宝/地形/其他分类正确。
- 面板位于 `(85,244)`、宽 `310`，按 40 + 行数×17 动态高，最多十行。
- 累计降序、占比条、近十秒秒伤、零输出在场武将和溢出提示均与 Web 一致。
- 结算战报显示输出前三占比。
- 网页与 Godot 使用同一固定账本生成 480×800 成对截图。
